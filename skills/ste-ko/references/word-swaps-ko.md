# 상투 표현 대체표

자동 치환표가 아니다. 문맥에서 사실을 해치지 않을 때만 바꾼다.
같은 뜻을 여러 말로 돌려 쓰지 않는다. 한 문서에서는 한 표현만 쓴다.

## 효과를 주장하는 말

| 쓰지 않는 표현 | 대신 쓰는 방법 |
|---|---|
| 강력한, 혁신적인, 획기적인 | 삭제한다. 측정값이 있으면 측정값을 쓴다. |
| 원활하게, 매끄럽게 | 삭제한다. 실제 동작을 쓴다. 예: "재시작 없이 적용된다." |
| 효율적으로, 최적화하여 | 무엇이 얼마나 줄었는지 쓴다. |
| 다양한, 여러 가지 | 종류를 나열하거나 개수를 쓴다. |
| 중요합니다, 핵심적입니다 | 중요한 이유를 사실로 쓴다. |
| 쉽게, 간편하게 | 단계 수나 걸리는 시간을 쓴다. |

## 도입과 맺음

| 쓰지 않는 표현 | 대신 쓰는 방법 |
|---|---|
| 좋은 질문입니다 | 삭제한다. 바로 답한다. |
| ~에 대해 살펴보겠습니다 | 삭제한다. 내용을 바로 쓴다. |
| 도움이 되길 바랍니다 | 삭제한다. |
| 필요하시면 말씀해 주세요 | 삭제한다. 결정이 필요하면 구체적인 질문을 쓴다. |
| 정리하면, 요약하면 | 이미 짧으면 삭제한다. |

## 명사화와 피동

| 쓰지 않는 표현 | 대신 쓰는 방법 |
|---|---|
| 분석을 수행한다 | 분석한다 |
| 점검을 실시한다 | 점검한다 |
| 확인을 진행한다 | 확인한다 |
| ~할 수 있도록 한다 | ~한다, 또는 ~하게 한다 |
| ~이루어진다 | 행위자를 주어로 쓰는 능동문으로 바꾼다 |
| 저장되어집니다 | 저장됩니다. 행위자가 중요하면 "시스템이 저장합니다" |

## 모호한 표현

| 쓰지 않는 표현 | 대신 쓰는 방법 |
|---|---|
| ~라고 할 수 있다 | 단정할 근거가 있으면 단정한다. 없으면 "확인하지 못함"이라고 쓴다. |
| 어느 정도, 다소 | 수치나 범위를 쓴다. |
| 등, 기타 | 목록을 끝까지 쓴다. 전체 목록의 위치를 쓸 수도 있다. |
| 것 (의존명사 남용) | 대상을 이름으로 쓴다. |

## 바꾸지 않는 것

- 원문에 있는 "일 수 있다", "약", "대략" 같은 확신 수준 표현
- 인용한 오류 메시지, 로그, 법령, 계약 문구
- 고유 이름과 표준 이름
