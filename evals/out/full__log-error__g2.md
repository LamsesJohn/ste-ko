`ConnectionRefusedError: [Errno 111] Connection refused`

테스트가 접속한 주소와 포트에서 받는 프로세스가 없다는 뜻입니다. 코드를 아직 보지 않아서 어느 서버인지는 확인하지 못했습니다.

가능한 원인은 다음과 같습니다.

1. 테스트가 필요로 하는 서버(DB, Redis, API 등)가 실행 중이 아닙니다.
2. 서버가 아직 시작을 끝내지 않았는데 테스트가 먼저 접속했습니다.
3. 테스트의 호스트나 포트 설정이 서버의 실제 값과 다릅니다.
4. `localhost`가 IPv6(`::1`)로 풀리는데 서버는 IPv4만 듣고 있습니다.
5. 컨테이너 안에서 `localhost`로 접속하고 있습니다. 이 경우 서버는 다른 컨테이너에 있습니다.

다음 순서로 확인합니다.

1. 트레이스백에서 접속 대상 주소와 포트를 찾습니다.
2. `ss -ltnp | grep <포트>`로 그 포트를 듣는 프로세스가 있는지 봅니다.
3. 프로세스가 없으면 서버를 시작하고 테스트를 다시 실행합니다.

전체 트레이스백을 붙여 주시면 접속 대상을 특정하겠습니다. 원하시면 이 디렉터리의 테스트 코드와 설정을 직접 찾아보겠습니다.
