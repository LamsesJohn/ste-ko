테스트가 접속하려는 주소에서 기다리는 프로세스가 없다는 뜻이야. Errno 111은 해당 host:port에 서버가 떠 있지 않을 때 나와.

로그에는 접속 대상이 없어서 어떤 서비스(DB, Redis, API 등)인지는 확인하지 못했어. 코드도 아직 읽지 않았어.

흔한 원인은 이래.
1. 테스트가 필요로 하는 서버나 DB를 아직 실행하지 않았다.
2. 테스트 설정의 포트가 실제 서버 포트와 다르다.
3. 서버가 `127.0.0.1`에만 바인딩했는데 테스트는 다른 주소로 접속한다.
4. 서버가 시작을 끝내기 전에 테스트가 먼저 접속했다.
5. 서비스가 Docker나 Windows 쪽에서 돌고 있어서 WSL2의 `localhost`로 닿지 않는다.

먼저 이 명령으로 해당 포트를 듣는 프로세스가 있는지 확인해 봐.

```bash
ss -ltnp | grep <포트>
```

결과가 비어 있으면 서버를 먼저 띄워야 해. 전체 트레이스백을 주면 접속 대상을 찾아 줄 수 있어. 아니면 내가 이 디렉터리에서 테스트 코드와 설정을 직접 읽어 볼까?
