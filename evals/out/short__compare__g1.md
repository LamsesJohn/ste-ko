Docker는 호스트 커널을 공유하는 가벼운 컨테이너이고, 가상 머신은 하이퍼바이저 위에서 별도 커널을 가진 완전한 운영체제입니다.

| 항목 | Docker 컨테이너 | 가상 머신 |
|---|---|---|
| 격리 단위 | 프로세스 | 하드웨어 전체 |
| 커널 | 호스트와 공유 | VM마다 별도 |
| 시작 시간 | 보통 1초 안팎 | 수십 초에서 수 분 |
| 이미지 크기 | 수십 MB에서 수백 MB | 수 GB |
| 자원 사용 | 적음 | 많음 |
| 격리 강도 | 상대적으로 약함 | 강함 |
| 운영체제 | 호스트 커널과 같은 계열만 가능 | 다른 운영체제 실행 가능 |
| 이식성 | 이미지 하나로 어디서나 실행 | 이미지가 크고 하이퍼바이저에 종속 |

**Docker를 고를 때**
1. 마이크로서비스나 CI 환경처럼 빠른 배포와 확장이 필요할 때 고릅니다.
2. 개발 환경을 팀원 모두에게 똑같이 맞추고 싶을 때 고릅니다.
3. 서버 한 대에 많은 애플리케이션을 밀도 높게 올리고 싶을 때 고릅니다.

**가상 머신을 고를 때**
1. 서로 신뢰하지 않는 테넌트를 강하게 격리해야 할 때 고릅니다.
2. Windows 서버 위에서 Linux를 돌리는 것처럼 다른 운영체제가 필요할 때 고릅니다.
3. 커널 수준 설정이나 커널 모듈을 직접 다뤄야 할 때 고릅니다.

두 기술은 함께 쓰는 경우가 많습니다. 클라우드에서는 VM 위에 Docker 컨테이너를 올려 두 장점을 합칩니다. 현재 환경이 WSL2이므로 Docker도 내부적으로 경량 VM의 Linux 커널을 사용합니다.
