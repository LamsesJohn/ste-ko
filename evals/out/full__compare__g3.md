Docker는 호스트 OS의 커널을 공유해서 가볍고 빠릅니다. 가상 머신(VM)은 게스트 OS를 통째로 실행해서 무겁지만 격리가 더 강합니다.

커널은 OS의 핵심부로, 하드웨어와 프로세스를 관리합니다. 하이퍼바이저는 VM을 만들고 실행하는 소프트웨어입니다.

| 항목 | Docker 컨테이너 | 가상 머신 |
|---|---|---|
| 구조 | 호스트 커널을 공유합니다. | 하이퍼바이저 위에서 게스트 OS가 자기 커널을 실행합니다. |
| 시작 시간 | 보통 몇 초 이내입니다. | OS를 부팅하므로 더 오래 걸립니다. |
| 자원 사용 | 이미지가 작고 메모리를 적게 씁니다. | 게스트 OS마다 디스크와 메모리를 씁니다. |
| 격리 수준 | 프로세스 단위로 격리합니다. 커널은 공유합니다. | 하드웨어 수준으로 격리합니다. |
| OS 선택 | 호스트와 같은 종류의 커널만 씁니다. | 호스트와 다른 OS도 실행합니다. |
| 이식성 | 이미지 하나로 어디서나 같은 환경을 만듭니다. | 디스크 이미지가 커서 옮기기 불편합니다. |
| 주 용도 | 마이크로서비스, CI, 배포 단위 | 서로 다른 OS 실행, 강한 보안 경계, 레거시 시스템 |

## 선택 기준

- 같은 커널에서 앱을 빠르게 배포하려면 Docker를 씁니다.
- 신뢰할 수 없는 코드를 실행하거나 다른 OS가 필요하면 VM을 씁니다.
- 둘을 함께 쓰는 경우도 많습니다. 클라우드에서는 VM 안에서 컨테이너를 실행해 두 장점을 모읍니다.

macOS와 Windows의 Docker Desktop은 내부에서 가벼운 Linux VM을 실행합니다. 이 환경에서는 컨테이너가 그 VM의 커널을 공유합니다.
