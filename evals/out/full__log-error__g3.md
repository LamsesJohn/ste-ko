`ConnectionRefusedError: [Errno 111] Connection refused`는 테스트가 접속한 주소와 포트에서 받는 프로세스가 없다는 뜻입니다. 이 로그만으로는 어느 서버에 접속했는지 확인하지 못했습니다.

가능한 원인은 다음과 같습니다.

- 테스트가 필요로 하는 서버나 서비스(DB, Redis, 로컬 API 등)가 실행 중이 아닙니다.
- 호스트나 포트가 틀렸습니다. 설정 파일이나 환경 변수가 테스트 환경에 맞지 않을 수 있습니다.
- 서버가 아직 시작을 끝내지 않았는데 테스트가 먼저 접속했습니다.
- 서버가 `127.0.0.1`에서만 받는데 테스트는 다른 주소로 접속합니다. 컨테이너나 WSL에서 자주 생깁니다.
- 방화벽이 접속을 막고 있습니다.

확인 순서는 다음과 같습니다.

1. 트레이스백에서 접속을 시도한 줄을 찾아 호스트와 포트를 확인합니다.
2. `ss -ltnp | grep <포트>`를 실행해 그 포트에서 받는 프로세스가 있는지 확인합니다.
3. 프로세스가 없으면 서비스를 시작하고 테스트를 다시 실행합니다.
4. 프로세스가 있으면 `curl -v <호스트>:<포트>`로 접속을 직접 시험합니다.

전체 트레이스백과 테스트 명령을 알려 주시면 접속 대상을 코드에서 찾아 원인을 좁히겠습니다.
