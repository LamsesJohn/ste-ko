대상 호스트와 포트에서 받는 프로세스가 없어서 연결이 거절되었습니다. 테스트 코드가 연결하려는 서버가 꺼져 있거나, 다른 주소나 포트를 보고 있을 가능성이 큽니다.

로그 한 줄만으로는 어느 서버인지 확인하지 못했습니다. 가능한 원인은 다음과 같습니다.

1. 테스트가 필요로 하는 서버(DB, Redis, API 등)가 실행 중이지 않습니다.
2. 서버는 실행 중이지만 테스트가 다른 포트로 연결합니다. 설정 파일이나 환경 변수의 값이 다를 수 있습니다.
3. 서버가 아직 시작을 끝내지 않았을 때 테스트가 먼저 연결합니다.
4. 서버가 컨테이너나 WSL 안에서 실행 중인데 `localhost`로 접근할 수 없습니다.

다음 순서로 확인합니다.

1. 전체 트레이스백에서 `connect` 호출의 호스트와 포트를 찾습니다.
2. `ss -ltnp | grep <포트>` 명령으로 그 포트를 듣는 프로세스가 있는지 봅니다.
3. 없으면 해당 서버를 시작하고 테스트를 다시 실행합니다.

전체 트레이스백이나 테스트 파일 경로를 알려 주시면 정확한 호스트, 포트, 호출 위치를 찾아 드리겠습니다.
